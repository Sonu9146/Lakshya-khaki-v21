# Lakshya Khaki Native v5

## Quiz upgrade
- Countdown timer: 30 seconds per question.
- Previous / Next navigation.
- Answer state is preserved when navigating.
- Unanswered questions are counted.
- Automatic finish when timer reaches zero.
- Result screen with score, percentage, attempted count and progress bar.
- Native Compose UI; no WebView.

The project remains source-only because this environment does not have Android SDK/Gradle available to compile an APK.
