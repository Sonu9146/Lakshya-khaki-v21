# Lakshya Khaki Native v7

## Progress Dashboard
- Native progress dashboard for 1600m, 100m and Shot Put.
- Personal Best summaries.
- Attempt counts and simple improvement trend.
- Percentage change between older and latest recorded performance.
- MCQ attempt count and overall accuracy.
- Weekly focus card.
- Uses Room history; no WebView.

This remains a source project. Android SDK/Gradle are not available in this environment, so an APK cannot be compiled here.
