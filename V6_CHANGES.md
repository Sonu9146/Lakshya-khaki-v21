# Lakshya Khaki Native v6

## Professional Ground Tracker
- Event tabs: 1600m, 100m, Shot Put.
- Saves performance attempts into Room.
- Supports time as seconds or mm:ss.
- Calculates event-specific Personal Best.
- Shows recent saved history with timestamps.
- Native Compose UI; no WebView.

Note: This is a source project. Android SDK/Gradle are not installed in this environment, so an APK cannot be compiled here.
