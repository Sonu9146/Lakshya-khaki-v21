# Lakshya Khaki Native v10

## Smart Reminder
- Native Android daily reminder using AlarmManager + BroadcastReceiver.
- Default reminder time: 7:00 PM.
- Reminder can be toggled on/off.
- Reminder hour can be adjusted from the native settings screen.
- Notification channel created for Android 8+.
- POST_NOTIFICATIONS permission declared for Android 13+.
- Existing Daily Goals, Progress, Ground, Quiz, Study and Achievements retained.
- No WebView.

Note: APK is not compiled in this environment because Android SDK/Gradle are unavailable.
