# Lakshya Khaki Native v20 — Final Fix

Source reviewed again before packaging.

Fixed:
1. Room QuizResult insertion now uses named parameters, avoiding the autogenerated `id` parameter mismatch.
2. GroundResult analytics uses the actual String storage format.
3. Analytics uses the existing time parsing/formatting helpers.
4. `context.db` references were corrected to the actual database singleton.
5. Added a CI-ready `.github/workflows/android.yml`.
6. CI uses JDK 17, Gradle 8.7 and `gradle :app:assembleDebug`.
7. Added `gradle.properties` with AndroidX and JVM settings.

The workflow also supports repositories that contain the native project directly or contain the project inside a source ZIP.

APK can only be produced by a machine/runner with Android build tooling available; GitHub Actions will provide the `lakshya-khaki-debug` artifact after a successful run.
